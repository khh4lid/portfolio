How BINA works

Two flows, one meaning.

Every sign has one ID, like SALAM, and both directions read the same catalogue of 21 meanings.

6signs the camera turns into a voice
  1. The Deaf person signs

    In front of the phone camera.

  2. The camera reads it

    A vision model returns one sign class.

  3. One meaning ID

    SALAM, the same ID that Flow 2 uses.

  4. The hearing person hears it

    In Arabic or English. Switching language needs no new sign.

Built on Cloudflare.

BINA's API is a Cloudflare Worker, with D1 for the catalogue and R2 for the avatar clips.

  • WorkersOne API for both apps, with auth checks, CORS and CSRF guards, rate limits and ETag caching.
  • D1SQL migrations. Every write is one atomic batch with a version check.
  • R2Avatar clips streamed with HTTP range requests.
  • AccessAdmin requests carry a Cloudflare Access token that the Worker verifies.
